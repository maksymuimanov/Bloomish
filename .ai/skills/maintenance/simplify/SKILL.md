# Simplify

## Purpose

Simplify complex code to improve readability and maintainability.

## Prerequisites

- Identify complex code that needs simplification
- Review `.ai/rules/kiss.md` and `.ai/rules/dry.md`
- Understand the current implementation

## Steps

1. **Identify complexity**
   - Find code that is hard to understand
   - Identify overly complex logic
   - Find code with many responsibilities
   - Check for unnecessary abstractions

2. **Analyze the complexity**
   - Understand why the code is complex
   - Determine if the complexity is necessary
   - Identify simplification opportunities
   - Assess the impact of simplification

3. **Design the simplification**
   - Break down complex logic into smaller pieces
   - Remove unnecessary abstractions
   - Extract repeated code
   - Use clearer naming

4. **Implement the simplification**
   - Make the code simpler
   - Follow KISS principles
   - Remove duplication
   - Improve naming

5. **Test the simplification**
   - Verify behavior is unchanged
   - Test edge cases
   - Run all tests
   - Ensure the code is more readable

## Verification

- Code is simpler
- Behavior is unchanged
- Code is more readable
- Duplication is reduced
- Naming is clearer
- Tests pass
- Code follows KISS and DRY principles
