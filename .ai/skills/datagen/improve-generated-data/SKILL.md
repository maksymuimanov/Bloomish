# Improve Generated Data

## Purpose

Improve the quality, consistency, or completeness of generated data.

## Prerequisites

- Understand the current generated data
- Review `.ai/rules/datagen.md`
- Identify areas for improvement

## Steps

1. **Analyze current generated data**
   - Review generated files
   - Identify inconsistencies
   - Find missing data
   - Check for incorrect data

2. **Identify improvements**
   - Determine what needs to be improved
   - Prioritize improvements
   - Assess impact on existing data
   - Plan the changes

3. **Update providers**
   - Modify providers to generate better data
   - Fix inconsistencies
   - Add missing data
   - Correct incorrect data

4. **Improve data consistency**
   - Ensure texture naming is consistent
   - Verify model properties are consistent
   - Check block state consistency
   - Ensure data matches registered objects

5. **Test the improvements**
   - Run data generation
   - Verify improvements are applied
   - Check for regressions
   - Ensure data loads correctly in-game

## Verification

- Generated data is improved
- No regressions introduced
- Data is consistent
- Data matches registered objects
- Data generation completes without errors
- Code follows datagen rules
